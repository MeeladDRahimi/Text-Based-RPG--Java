# Text-Based RPG (java)

### Key Features:
##### - Save and Quit Mechanics
##### - Game Progression (Dynamic Enemies, Story Acts, Necessary Actions to Progress)
##### - Equipment System (Over 140 Unique Items to Collect)
##### - Shops (Buy, Sell, or Buy Back Equipment. Items Available Change Per Act and Reload of the Game)
##### - Player Progression (Power Ups and Leveling)
##### - Traversable Map (6 Locations Per Act: 24 Locations)
##### - Battle Sequence (Randomized Enemies, Bosses, Boss Loot, etc.)

### Future Fixes and Additions:
##### - Better Organization (Comments, MVC, Contracts, UML Diagram)
